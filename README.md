# ЛЛ1 — оценка языковых моделей с открытыми весами

Экспериментальная работа магистерского уровня с реальной локальной генерацией на CPU.
Все авторские отчёты, пояснения, комментарии в коде и подписи графиков — на русском.
Язык исходного эксперимента — румынский; входы, ответы и численные результаты сохранены.

## Скачать и запустить локально в Windows

**[Скачать готовый проект ZIP с GitHub](https://github.com/alinaRN1/llm1/raw/refs/heads/main/downloads/LL1_masterat_ru.zip)**

Если браузер открывает страницу файла, нажмите кнопку скачивания файла в GitHub.
Распакуйте архив и откройте папку `LL1_masterat`: непосредственно в ней должны лежать
`README.md`, `laborator.ipynb`, папки `data`, `results` и `src`.

Для просмотра и выполнения анализа готовых результатов подходит Python 3.10 или новее.
Откройте PowerShell **в папке с `laborator.ipynb`** и выполните:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install jupyterlab ipykernel numpy pandas matplotlib
.\.venv\Scripts\python.exe -m ipykernel install --prefix .\.venv --name llm1 --display-name "ЛЛ1"
.\.venv\Scripts\python.exe -m jupyter lab laborator.ipynb
```

В браузере выберите ядро «ЛЛ1» и нажмите «Run → Run All Cells».
Этот путь выполняет анализ сохранённых 360 ответов. Инструкции полного повторного
запуска моделей приведены ниже; исходный эксперимент проверен на Python 3.12.

Архив в `downloads` содержит проект, отчёты и результаты; веса моделей и виртуальные
окружения исключены. Сборка архива: `python src/package_project.py`. Файл
`checksums.sha256` относится к содержимому проекта внутри архива. Папка `downloads`
внутрь него не включается, чтобы исключить вложение архива в самого себя.

## Материалы

- `reports/raport.pdf`, `raport.docx`, `raport.md` — методика, результаты, графики, проверка и выводы.
- `laborator.ipynb` — выполненный блокнот с реальными результатами.
- `reports/defense_ru.md` — краткие пояснения для защиты.
- `data/questions.json` — исходные 20 вопросов: 6 по истории, 6 по румынскому языку, 8 по математике.
- `data/questions_ru.json` — русский перевод для чтения; моделям он не передавался.
- `data/models_oci.lock.json` — неизменяемые SHA-256 трёх моделей.
- `results/final/` — все 360 ответов, манифест, ресурсы, оценки, интервалы и графики.
- `data/review_decisions.json` — русские пояснения проверки, связанные с хешами ответов.
- `reports/tests.xml` — программная проверка оценщика, отделённая от качества моделей.
- `licenses/` — исходные тексты лицензий; веса в архив для сдачи не включены.

## Модели и протокол

| Пакет Docker AI | Вариант | Формат |
|---|---|---|
| `ai/qwen2.5:0.5B-F16` | Qwen2.5-0.5B-Instruct | GGUF F16 |
| `ai/smollm2:360m-f16` | SmolLM2-360M-Instruct | GGUF F16 |
| `ai/llama3.2:1B-F16` | Llama-3.2-1B-Instruct | GGUF F16 |

Регистр важен: `360M-F16` содержит базовую модель, а `360m-f16` — Instruct.
Вариант подтверждён метаданными GGUF.

Три модели × 20 вопросов × два режима × три повтора = 360 измеренных ответов.
Жадное декодирование сравнивается с выборкой: T=0,2, top-p=0,9, штраф повторения=1,1.
Дообучения нет. Используются 4 потока CPU, контекст 1024, до 160 новых токенов,
без GPU и общего кеша префикса. Два прогревочных запроса на модель исключены из статистики.

Прямой доступ к Hugging Face был закрыт. Артефакты скачаны из разрешённой дистрибуции
Docker AI. Для итогового пути не нужны Docker daemon, учётная запись реестра, токен
Hugging Face или новая сетевая политика. Проверки TLS и контрольных сумм включены.

## Полное воспроизведение эксперимента

Нужны Python 3.12, GCC/G++, примерно 8 ГБ памяти и 10 ГБ свободного места.
В облаке проект находится в `/workspace/llm1`. Дополнительное рабочее дерево Git
не создаётся: задача уже изолирована. `install.sh` автоматически находит корень
и работает после распаковки проекта в другую папку.

```bash
cd /workspace/llm1
bash install.sh
.venv/bin/python src/pull_oci.py --locked data/models_oci.lock.json
.venv/bin/python src/benchmark_gguf.py --run-id replicare-01
.venv/bin/python src/analyze.py results/runs/replicare-01
```

Скачивание использует `auth.docker.io`, `registry-1.docker.io` и CDN Docker через
унаследованный прокси. Каждый манифест и файл проверяется SHA-256. Не отключайте
прокси, TLS или проверку контрольных сумм.

Новый запуск сохраняет реальные ответы, вероятности и измерения. Если тексты
отличаются, нужна новая проверка содержания. Старое заключение применимо только
к той же модели, заданию и точному хешу ответа. Перед новым итоговым отчётом
заполните решения для всех новых текстов и выполните `audit.py` и `analyze.py`.

Для пересборки сохранённого эксперимента без скачивания и повторной генерации:

```bash
.venv/bin/python src/audit.py results/final data/review_decisions.json
MPLCONFIGDIR=/tmp/llm1-mpl .venv/bin/python src/analyze.py results/final
.venv/bin/python src/build_report.py --run results/final
.venv/bin/python src/build_notebook.py
```

Экспорт PDF/Word требует Pandoc и XeLaTeX, уже установленных в облаке.
Блокнот использует локальное ядро `llm1` из `.venv`; открывайте его из корня проекта.
Флаг `RUN_NEW_EXPERIMENT=False` оставляет режим анализа сохранённых приложений.

## Таблицы и язык данных

Таблицы с суффиксом `_ru.csv` имеют русские заголовки и названия режимов. Экспорты
без суффикса сохраняют машинную схему, которую читают скрипты. Идентификаторы
API, имена моделей, хеши и исходные цитаты не переводятся. В таблицах проверки
оригинальный ответ остаётся на румынском, а заключение проверяющего — на русском.

Официальные лицензии, исходный PDF задания и сторонняя документация сохранены
дословно как источники. Они не являются авторскими комментариями или отчётами.

## Интерпретация

Строгая оценка требует маркера `RĂSPUNS FINAL:` и совпадения с эталоном.
Проверка содержания отдельно оценивает знание и числовой результат. За подпись
«Шаг 1» либо готовое равенство без промежуточных вычислений баллы за шаги не начисляются.
Правильный результат, верные шаги и полное решение — разные переменные.
Поле `format_ok` обозначает присутствие маркера, а не правильность следующего за ним текста.

Интервалы Уилсона относятся к первому повтору с n=12/8; бутстреп группирует повторы
по вопросам. Референсная PPL не измеряет истинность. Стоимость инфраструктуры
характеризуется ресурсами и формулой с реальным тарифом; цена и энергопотребление не выдумываются.

Проверка содержания выполнена одним ИИ-ассистентом без независимой человеческой
оценки. Небольшой набор и компактные модели ограничивают обобщение выводов.

`src/benchmark.py` сохраняет альтернативную реализацию Transformers начального этапа.
Итоговые измерения получены через `src/benchmark_gguf.py`.
